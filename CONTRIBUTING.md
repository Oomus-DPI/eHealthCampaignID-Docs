# Contributing

Thanks for helping improve the Oomus eHealth CampaignID documentation.

## Contribution Rules

- Keep documentation public-safe: do not add secrets, credentials, customer data, internal contracts or real DHIS2 exports.
- Prefer concise Markdown with clear headings and tables.
- Use relative links between documents.
- When documenting an integration, separate public configuration guidance from private operational details.
- When adding examples, use placeholder values such as `<api-url>`, `<token>` and `<programme-id>`.

## Pull Request Checklist

- The change is limited to public documentation.
- Links were checked.
- No `.env`, credentials, private keys, tokens or customer data were added.
- Any screenshots or assets are anonymized.
