# Code of Conduct

This documentation project is maintained for professional collaboration between Oomus, partners, integrators and technical teams.

Participants are expected to:

- Communicate respectfully and constructively.
- Keep discussions focused on documentation, integration and implementation quality.
- Avoid sharing private data, credentials, confidential contracts or sensitive operational details.
- Report security issues through the private process described in [SECURITY.md](./SECURITY.md).

Maintainers may remove content or close discussions that are abusive, confidential, off-topic or unsafe for a public repository.
