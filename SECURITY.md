# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities.

Report suspected vulnerabilities privately to the OOMUS maintainers with:

- A clear description of the issue.
- Steps to reproduce when applicable.
- Affected document, endpoint or integration.
- Any suggested remediation.

## Public Documentation Safety

This repository must not contain:

- Secrets, tokens, private keys or service account JSON files.
- Real beneficiary records or DHIS2 exports.
- Internal risk registers.
- Full internal security procedures.
- Contractual SLA terms or private legal documents.
